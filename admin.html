Mac Admin 管理頁

Pending 審核、Commit、完整報告、更新中心、診斷報告。此頁需要 Mac Host token；輸入一次後 15 分鐘有效，Mac Host 重新啟動後舊 token 會失效。

回前台 App

1. Token 登入

請輸入 Mac 終端機顯示的 One-time Sync Code / Token。Token 每次啟動不同。輸入並驗證一次後，瀏覽器會保留 15 分鐘；若 Mac Host 重新啟動，token 會改變，驗證失敗時會自動清除。手機送出 pending 不需要 token；Mac 端 Approve / Reject / Commit / 更新 / 診斷才需要 token。

2. Pending Queue 審核

      
R18-r8：日常流程可在 Admin 一頁完成。先按「從 Cloudflare 拉取 Pending 並刷新」，人工 Approve / Reject；Commit 成功後會自動回寫 Worker 狀態。若雲端回寫失敗，本機 commit 不回滾，可重試同步。

      

      

    


    

      
3. 完整報告中心

      
已 Commit 的正式報告會出現在這裡；local pending 的完整內容可在手機/前台 Local Records 裡展開「完整報告」。

      
      

      

    


    

      
4. 更新中心

      
r16 支援完整 GUI 更新與 latest code backup rollback；r11 起支援完整 GUI 更新：匯入 update ZIP → 檢核 VERSION.json → 建立安裝前備份 → 複製新版程式檔並保留 data/diagnostic/updates。安裝完成後需要重新啟動 Mac Host 才會載入新版程式。

      
      
      
      

        
        
        
        
        
      

      

    



    

      
4B. Cloud Sync Lab

      
R18-r8 後 Cloud Sync Lab 主要作為 Cloudflare 設定、診斷與補救入口；日常拉取、審核、commit、狀態回寫優先在 Admin 頁完成。

5. 匯出診斷報告

      
診斷報告會輸出到 app 根目錄下的 diagnostic/ 資料夾，同時產生 JSON 與 MD。

      
      
      

    


    

      
6. 舊版 SQLite 匯入 / 合併

      
如果新版解壓在新資料夾，上一版已 commit 的報告會留在舊版 data/app.sqlite3。請選擇舊版 app.sqlite3，先 Preview，再 Apply Merge。匯入後仍會套用「同一個股只保留最近 3 份正式報告」。

      
      
      

        
        
      

      

    


    

      
7. 備份 / 匯出

      
Retention：備份與 update artifacts 只保留最近 2 份；診斷報告只保留最近 5 組；同一個股正式報告只保留最近 3 份。
