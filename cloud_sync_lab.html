Cloudflare Sync Bridge

R18-r6 GUI 驗證頁：使用現有 8765 Mac Host 作為安全代理，連接 Cloudflare Worker / D1。Secret 只送到本機 Mac Host，不寫入 GitHub Pages。

回 Mac Admin ｜ 回前台 App

1. Mac Host / Token

請先確認 Mac Host 正在執行，並輸入本次終端機顯示的 One-time Sync Code / Token。不要把 token 貼給任何人。


    


    

      
2. Cloudflare Bridge 設定

      
這裡只設定本機 Mac Host 的 bridge。測試 secret 可用 Cloudflare D1 裡建立的 test device / host；正式 secret 請另行註冊後再填。

      
      
      
      
      
      
      
      
      
      
      

        
        
        
      

      

    


    

      
3. GUI E2E 測試

      
依序執行：送測試 pending 到 Worker/D1 → Host pull/import 到本機 pending_queue → 回 Admin 審核/commit → 同步本機狀態回 Worker。

      

        
        
        
      

      

    


    

      
4. 狀態回寫

      
在 Admin 頁面對 cloud pending 做 Approve / Commit 後，回到這裡輸入 pending_id，同步本機狀態到 Worker。

      
      
      

        
        前往 Admin 審核
      

      

    


    

      
5. 驗收標準

      
    
        
  • /admin.html、/、/manifest.json、/api/health 必須維持 200。
    • 
        
  • Worker health 必須 ok:true。
    • 
        
  • Signed test submit 後，pull/import 應將 TEST 放入本機 Pending Queue。
    • 
        
  • Admin 可看到該 pending，且可 Approve / Commit。
    • 
        
  • 狀態回寫 Worker 後，Worker/D1 狀態應與本機一致。
